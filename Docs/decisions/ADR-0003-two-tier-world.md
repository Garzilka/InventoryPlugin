# ADR-0003: Двухуровневая архитектура — генплан + чистая функция участка

- **Дата:** 2026-10-26
- **Статус:** принято
- **Связано:** [02-data-contract.md](../02-data-contract.md)

## Контекст

Черновик описывал один линейный конвейер по всему миру (шум → макро → микро → реки → дороги →
город). В такой схеме нельзя построить отдельный участок: ему нужен результат глобальных
проходов. Плюс любые «дельты» и «файлы участков» создают швы на границах.

## Варианты

1. **Один глобальный конвейер** + нарезка результата на участки (как в черновике).
2. **Дельты на чанк** с захватом соседних вершин (как предлагал черновик).
3. **Два уровня:** маленький глобальный «генплан» + чистая функция `участок(cx, cy)`.

## Решение

**Вариант 3.**

- **Генплан (WorldDNA)**: размер мира, регионы, гидрограф, дорожный граф, поселения, зоны, POI.
  Считается один раз, маленький (десятки–сотни КБ), передаётся клиенту.
- **Участок** = чистая функция `(генплан, cx, cy)` → высоты, маски, грунт, раскладка структур.
  Считается лениво, параллельно, в любом порядке.

## Следствия

- ✅ Швы исчезают по построению: граничные значения вычисляются из одних и тех же входов.
- ✅ Мир любого размера, ленивая загрузка, без хранения мира на диске.
- ✅ Клиент и сервер получают одинаковый результат без «истории вычислений».
- ⚠️ Всё, что требует глобального знания (реки, дороги, города), обязано быть в генплане.
  Внутри участка — только локальные правила.
- ⚠️ Изменение генплана меняет весь мир (нужна версия генератора и CI с хешами).
