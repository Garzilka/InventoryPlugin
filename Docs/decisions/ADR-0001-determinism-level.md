# ADR-0001: Уровень детерминизма «Г» (гибрид)

- **Дата:** 2026-10-26
- **Статус:** принято
- **Связано:** [01-determinism.md](../01-determinism.md)

## Контекст

Мир строится в рантайме из сида. Клиент и сервер должны получить одинаковый мир. Сервер и
клиент могут однажды оказаться на разных ОС/компиляторах (Linux-сервер). Дробные числа дают
различия на уровне последнего бита, которые через миллионы проверок превращаются в другой мир.

## Варианты

1. **А.** Всё на целых числах — максимальная строгость, дороже в разработке.
2. **Б.** Один и тот же билд на клиенте и сервере — можно дробные, но при смене платформы мир поедет.
3. **В.** Сервер авторитарен, клиент строит как получится, при расхождении сервер досылает данные.
4. **Г.** Гибрид: критичное для игры — целые числа; внешний вид — дробные; плюс проверка хешами.

## Решение

**Вариант Г.** Целые числа (сантиметры, `uint16` для углов, `0…10000` для плотностей) во всём,
что влияет на геймплей. Дробные — только в рендере, звуке и косметике, которая не влияет на
решения. Дополнительно: хеши генплана и участков, сравнение с сервером, аварийная досылка данных.

## Следствия

- ✅ Геймплей защищён от расхождений даже при смене платформы.
- ✅ Косметику можно писать обычным кодом, не выкручивая руки.
- ⚠️ Нужен собственный слой математики: таблицы синусов, целочисленный шум.
- ⚠️ Обязателен CI с эталонными хешами, иначе правило превратится в пожелание.
- ⚠️ Граница «критичное / косметика» должна проверяться на ревью каждого нового графа PCG.
