# ADR-0002: Свой меш-террейн вместо стандартного ландшафта UE

- **Дата:** 2026-10-26
- **Статус:** принято
- **Связано:** [04-terrain-and-collision.md](../04-terrain-and-collision.md)

## Контекст

Мир должен строиться в момент подключения игрока к серверу. Размер мира — переменный.
Стандартный ландшафт UE (`Landscape`) создаётся в редакторе, хранится как ассет и имеет жёсткий
предел размера (≈ 8160 × 8160 квадов). `World Partition` — тоже редакторная система.

## Варианты

1. **Стандартный ландшафт**, запечённый в редакторе.
2. **Стандартный ландшафт**, создаваемый в рантайме.
3. **Свои меши участков** с самостоятельным управлением детализацией.

## Решение

**Вариант 3.** Свой генератор мешей участков 256 × 256 м с уровнями детализации 1/2/4/8/16/32 м,
юбками по периметру для скрытия стыков и объединением в супер-участки на дальних дистанциях.

## Следствия

- ✅ Мир любого размера, генерация в рантайме, полный контроль над данными.
- ✅ Генерация чанков независима и параллельна.
- ⚠️ Приходится самим делать: уровни детализации, юбки, коллизию, раскраску (RVT),
  растительность (HISM/PCG), воду, сетку проходимости.
- ⚠️ Теряем редакторные инструменты ландшафта (кисти, слои) — компенсируем своим просмотрщиком.
- ⚠️ Nanite для террейна недоступен (только для ассетов).
